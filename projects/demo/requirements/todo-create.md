# Create Todo Item

## Feature
Todo Management

## Priority
High

## Description
A user should be able to add a new todo item in the TodoMVC application and see it in the active todo list.

## Preconditions
- TodoMVC application is available

## Acceptance Criteria
- User can enter a non-empty todo title
- Pressing Enter creates the todo item
- The created todo is visible in the list
- The active item count is updated

## Test Steps
1. Open the TodoMVC application
2. Enter a unique todo title in the new-todo input
3. Press Enter
4. Verify the new todo appears in the list

## Expected Results
- New todo is displayed
- New todo is active and not completed

# User Management CRUD

## Feature
User Management

## Priority
Critical

## Description
Admin should be able to create, update, and delete users from the SDET Practice application.

## Acceptance Criteria
- Admin can create a new user with valid details
- Created user appears in the user list
- Admin can update an existing user
- Updated user information is displayed correctly
- Admin can delete an existing user
- Deleted user no longer appears in the user list

## Test Steps

### Create User
1. Login as admin
2. Enter valid user details
3. Submit the user form
4. Verify the new user appears in the list

### Update User
1. Select an existing test user
2. Update the user details
3. Save the changes
4. Verify updated information is displayed

### Delete User
1. Select an existing test user
2. Delete the user
3. Confirm deletion
4. Verify the user no longer appears in the list

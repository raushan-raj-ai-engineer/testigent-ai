## Environment limitation

The build sandbox could not complete a fresh npm dependency installation within the network/transport window, so the full Playwright/browser CI suite was not falsely reported as executed here. The release retains its pinned dependency lock and adds the new browser-free contract to `validate:final:steps`; in a normal development/CI environment run:

```bash
npm ci
npx playwright install chromium
npm run validate:final
```

Live headed exploration additionally requires reachable target applications and, for Jira, real Jira credentials.

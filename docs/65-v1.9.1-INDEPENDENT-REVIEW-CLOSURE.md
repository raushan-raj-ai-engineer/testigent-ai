# TestigentAI v1.9.1 — Independent Review Closure

## Status

v1.9.1 is a corrective hardening candidate built after the independent v1.9.0 architecture/product review dated 14 September 2026. It does not move or rewrite the immutable `v1.9.0` tag.

The objective is to close all 14 reproduced findings (R01–R14) with code changes, executable regression coverage, and release-gate enforcement before a new release is certified.

## Release restrictions

Until v1.9.1 completes the same connected certification chain used for v1.9.0, this is a review candidate, not a certified replacement. The immutable v1.9.0 release remains the current certified baseline.

The reporting freeze remains active. Changes in this candidate are permitted corrective security/correctness/compatibility hardening and do not reopen the reporting feature surface.

## Mandatory verification

Run on supported Node 22 after a clean `npm ci`:

```bash
npm run typecheck
npm run test:review:closure
npm run release:static
npm run showcase:validate
npm run validate:final
npm run security:check
```

Then repeat PR CI/rerun, main CI/rerun and the full five-job release-compatibility matrix before creating any v1.9.1 tag.

# TestigentAI v1.10.3 — Public Project Overview

## One-line description

**TestigentAI is a production-style Playwright + TypeScript Quality Engineering platform for UI, API and Database automation, AI-assisted test authoring, governed self-healing, multi-project CI/CD and business reporting.**

## Problem it addresses

Many automation repositories scale by adding more tests but not by improving ownership, architecture, reporting or governance. TestigentAI treats automation as an engineering platform rather than a folder of browser scripts.

The platform separates:

- reusable framework capability;
- product-owned business behavior;
- deterministic quality facts;
- optional AI assistance;
- human approval and promotion;
- business reporting from low-level execution mechanics.

## Unified authoring example

```bash
npm run qa -- create JIRA:PAY-142 --auto-explore
```

or:

```bash
npm run qa -- create JIRA:PAY-142 \
  --learn="Create Order Journey" \
  --reviewer="QA Lead" \
  --review-and-promote
```

The generated proposal is validated and review-gated before it becomes active automation.

## Architecture principle

```text
Reusable capability -> src/framework/
Product knowledge    -> projects/<project>/
```

That boundary allows multiple applications/customers to share the same technical platform without sharing product-specific locators, APIs, SQL or business expectations.

## Release Compatibility matrix portability closure

The first connected v1.7.0 Release Compatibility matrix exposed a deterministic command portability defect.

The workflow correctly selected each Playwright browser through `PW_BROWSERS`, but `test:agentic:deterministic` also hardcoded `--project=chromium`. As a result, the Chromium lanes passed while Firefox and WebKit lanes failed before executing the deterministic agentic contracts because only the matrix-selected Playwright project was available.

The correction:

- removes the hardcoded Chromium project from `test:agentic:deterministic`;
- delegates project selection to the existing `PW_BROWSERS` Playwright configuration;
- adds a release-static regression guard that rejects any future hardcoded Playwright project in the deterministic agentic command;
- verifies the compatibility workflow continues to map `PW_BROWSERS` from `matrix.browser`;
- validates the deterministic agentic suite independently with Chromium, Firefox and WebKit browser selections.

No browser lane was skipped or weakened, and no retry, timeout increase or non-blocking workaround was introduced.

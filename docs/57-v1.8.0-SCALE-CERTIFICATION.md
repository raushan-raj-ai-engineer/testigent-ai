# TestigentAI v1.8.0 — Scale Certification Harness

## Truth boundary first

TestigentAI already has sharding and duration planning. That is not the same as proving 500 or 2,000 real tests. v1.8.0 therefore separates **synthetic planning diagnostics** from **measured execution certification**.

## Synthetic planning diagnostics

Use these to exercise planner completeness and shard balancing without making throughput claims:

```bash
npm run benchmark:scale:plan:500
npm run benchmark:scale:plan:2000
```

A planning result is always explicitly labelled `synthetic-planning-diagnostic`. It cannot certify browser, infrastructure or SUT throughput.

## Measured scale evidence

Measured evidence uses:

```text
schemas/testigent-scale-evidence.schema.json
benchmarks/examples/measured-scale-evidence.template.json
```

The input records:

- exact application/environment and dataset version;
- exact test selection/profile/lane;
- case count and executed count;
- duplicate and dropped case counts;
- workers and shards;
- wall-clock and per-shard durations;
- optional report-merge time and peak RSS;
- product version and source commit;
- runtime/platform and runner/hardware/cloud description;
- methodology;
- failures/exclusions;
- raw evidence reference.

On ingestion, TestigentAI computes and stores SHA-256 for the supplied evidence file.

```bash
npm run benchmark:scale:evaluate -- \
  --input=benchmarks/measured-scale-500.json
```

## Evaluation rules

A measured run fails when:

- executed cases do not equal expected cases;
- duplicate cases are detected;
- cases are dropped;
- shard imbalance exceeds the evidence threshold (25%).

Evidence remains `INSUFFICIENT_EVIDENCE` when:

- it is synthetic;
- required provenance is incomplete;
- fewer than 100 cases were measured.

A `PASS` certifies only the supplied measured run. A 500-case pass is evidence for that 500-case run; it is not a 2,000-case claim. A 2,000-case claim requires a measured 2,000-case run.

## Recommended release evidence sequence

```text
100 measured cases  -> smoke-scale evidence
500 measured cases  -> team-scale evidence
2,000 measured cases -> large-suite evidence
```

Capture and retain raw CI artifacts alongside the immutable benchmark record so reviewers can reproduce the derived metrics.
